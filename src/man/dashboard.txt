dashboard - a status wall on a projector

SYNOPSIS
  dashboard [--once] [--every SECONDS] [--fb /dev/fbN]
  dashboard start | stop

DESCRIPTION
  Draws a status wall on an OC2 projector (640x480): energy with a bar per
  storage, active alerts, this computer's memory and disk, the swarm (each
  computer with a green, yellow or red dot; drones show their battery), and
  the open tasks. Parts are redrawn only when they change.

  Setting up the projector:
    1. Shut the computer down (OC2 only finds a projector at start-up).
    2. Connect the projector to the computer with bus cables, or place it
       right next to the computer.
    3. Power it directly: an energy cable or power source touching it. The
       bus cable is not enough; a red lens means no power.
    4. Keep the block in front of the lens free (it projects onto the wall
       behind that, up to 12 blocks away).
    5. Start the computer, check `ls /dev/fb0`, then run `dashboard start`.
  It keeps running and starts again at every boot until `dashboard stop`.
  While it runs, the Linux text console is detached from the projector.

  On the main computer of a swarm, the dashboard shows the whole swarm:
  put it on a wall in your control room.

FILES
  /etc/shulker/dashboard.enabled   start at boot
  /tmp/shulker-dashboard.log       errors
