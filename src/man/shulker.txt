shulker - updates, apps and system checks

SYNOPSIS
  shulker version
  shulker update [--check] [--branch NAME]
  shulker list | search WORD
  shulker install APP... | remove APP...
  shulker doctor
  shulker linux [status | kernel | install [DEV]]
  shulker disks [status | setup [--raid0|--linear|--raid1|--separate] | mount]
  shulker mkdisk [lab|robot|plain] [--all | /dev/vdX ...] [--yes]
  shulker slim [--yes]
  shulker setup
  shulker enable|disable claude
  shulker uninstall [--purge]

DESCRIPTION
  update     downloads the current Shulker OS from GitHub
             (github.com/LinuxDino/ShulkerOS) and replaces the files that
             changed, then updates installed apps. Files are downloaded to
             /tmp and checked against SHA-256 sums first, and the free disk
             space is checked before anything is written. Your tasks, jobs,
             key and settings are kept. --branch switches (and remembers) a
             branch.
  list       the apps in the repository; * marks installed ones
  install    installs apps into /usr/local/shulker/pkg/APP, with commands
             linked into /usr/local/bin and man pages into
             /usr/local/shulker/man
  doctor     checks disk, memory, services, the device bus, the network
             (netcfg test) and Claude (claude doctor)
  linux      Shulker Linux is Sedna with a kernel that knows RAID (MD),
             ext4, overlayfs and loop devices, plus tmux, mdadm and curl
             with CA certificates (HTTPS that checks certificates).
               status   OS name, kernel, RAID support, drives
               kernel   replaces /boot/Image with the Shulker Linux kernel
                        (checked against SHA256SUMS; the old one is put back
                        if writing fails). Reboot to use it. Gives RAID
                        and ext4 without reinstalling.
               install  writes the whole Shulker Linux system (16 MB) to an
                        empty drive (DEV, or the first free one) and copies
                        /root, /etc/shulker, passwords, hostname, network
                        and ssh keys onto it. Then shut down, put that drive
                        in the first slot and start the computer.
  disks      the drives other than the system drive, used as /data:
               --raid0     one striped volume, all the space (default with RAID)
               --linear    one volume, drives one after another
               --raid1     mirrored: survives a lost drive, space of one
               --separate  each drive on its own: /data/1, /data/2, ...
                           (the only choice on the stock Sedna kernel)
             On stock Sedna: shulker linux kernel, reboot, shulker install
             mdadm, then setup. Running setup again replaces /data (asks).
             setup erases the free drives. /data is mounted at every boot
             from /etc/shulker/disks.conf. The system drive is never used:
             with 4 bays you get the system plus 3 drives of /data.
  mkdisk     the disk maker: turns blank hard drives in this computer's
             other bays into ready Shulker drives. It downloads the slim
             system once (Sedna without MicroPython and tcc, with the RAID
             kernel and mdadm: about 1.2 MB stays free on an 8 MB drive),
             copies it to the other blank drives, and puts this computer's
             own Shulker OS on each, so run `shulker update` first.
             Without a type it asks:
               lab    (node) joins the swarm main at 10.42.0.1 by itself,
                      and at its first start turns the other drives of its
                      computer into /data (RAID 0), erasing them; jobs run
                      in /data
               robot  (drone) for a robot's one drive bay: joins through
                      its drone base (a lab computer with a tunnel card,
                      `swarm base`), reports battery and position, goes
                      home to its charger when low
               plain  the setup wizard runs at the first login
             Then shut down, take the drives out, put each one in the first
             bay of a computer. Empty floppy/flash drives are never used.
  slim       removes MicroPython and the tcc C compiler from stock Sedna
             (about 650 KB), which Shulker OS and the swarm never use. Do it
             on 8 MB drives before `shulker install mdadm`.
  setup      the setup wizard (role, name, password, network, extras)
  enable/disable claude
             turns the optional Claude assistant on or off
  uninstall  removes Shulker OS from the disk (keeps ~/.shulker unless
             --purge)

  When Shulker OS runs from the data pack (/mnt/builtin/shulker, read-only),
  update the data pack instead, or run the installer to put a copy on disk.

APPS
  cowsay, fortune, matrix, snake, lsbus (see `shulker list`)

SECURITY
  On Shulker Linux, downloads use curl and check certificates. On stock
  Sedna they use BusyBox wget, whose HTTPS does not verify certificates. The
  SHA-256 sums come over the same connection, so they catch broken
  downloads, not a deliberate man-in-the-middle.

FILES
  /etc/shulker/disks.conf    mode= and devices= of /data
  /etc/shulker/repo.conf     repo=URL and branch=NAME
  /opt/shulker/manifest.txt  what is installed
  /usr/local/shulker/installed
